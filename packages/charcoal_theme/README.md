# charcoal_theme

Theme contract for Charcoal UI on Flutter Material: colour roles, scales, per-family metrics,
`CharcoalThemePack` and `CharcoalTheme` (a `ThemeExtension`).

Batch 1.1 froze the names; see `docs/theme-contract.md` in the repository root. The pack in
`lib/src/packs/temporary_pack.dart` is hand-written and is replaced by the generated pack in batch 1A.
